## Cuadrícula de datos

CoreUI React Data Grid gestiona más de 100.000 filas con ordenamiento, filtrado, virtualización, fijación de columnas, edición en línea y exportación CSV, utilizando el mismo marcado y hoja de estilos que ya utiliza esta plantilla.

```bash
npm install @coreui/react-data-grid
```

Una sola licencia también cubre JavaScript, Vue y Angular. Es un complemento independiente y no forma parte de CoreUI PRO.

## Inicio rápido

- [Download the latest release](https://github.com/coreui/coreui-free-react-admin-template/archive/refs/heads/main.zip)
- Clone the repo: `git clone https://github.com/coreui/coreui-free-react-admin-template.git`

### Instalación

``` bash
$ npm install
```

or

``` bash
$ yarn install
```

### Uso básico

``` bash
# dev server with hot reload at http://localhost:3000
$ npm start 
```

or 

``` bash
# dev server with hot reload at http://localhost:3000
$ yarn start
```

Navega a [http://localhost:3000](http://localhost:3000). La aplicación se recargará automáticamente si modificas cualquiera de los archivos fuente.

#### Compilación

Ejecuta `build` para compilar el proyecto. Los archivos generados se almacenarán en el directorio `build/`.

```bash
# build for production with minification
$ npm run build
```

or

```bash
# build for production with minification
$ yarn build
```

## Desarrollo compatible con IA

Esta plantilla está optimizada para el desarrollo asistido por IA, con archivos de contexto completos y documentación:

### Archivos de contexto
- **`.cursorrules`** - Archivo de contexto completo para IA con las convenciones, patrones y pautas del proyecto para trabajar con React, CoreUI y la arquitectura de la plantilla
- **`ARCHITECTURE.md`** - Documentación técnica detallada que cubre la estructura del proyecto, la jerarquía de componentes, el sistema de rutas, la gestión del estado y el proceso de compilación
- **`DEVELOPMENT.md`** - Guía práctica para desarrolladores con instrucciones de configuración, flujos de trabajo de desarrollo, ejemplos de código y buenas prácticas

### Documentación del código
- Todos los componentes React incluyen comentarios JSDoc detallados con tipos y descripciones de parámetros
- Documentación en línea que explica la lógica y los patrones complejos
- Definiciones de PropTypes para la comprobación de tipos en tiempo de ejecución

### Beneficios para los asistentes de programación con IA

Al utilizar asistentes de programación con IA como Cursor, Claude Code o GitHub Copilot, estos archivos de contexto ayudan a la IA a:

- **Comprender el stack**: Reconocer que se trata de una aplicación React 19 que utiliza componentes CoreUI React (no Tailwind CSS ni otros frameworks)
- **Seguir los patrones**: Generar código que coincida con la estructura de componentes y las convenciones del proyecto
- **Utilizar los componentes correctos**: Sugerir componentes CoreUI React apropiados de `@coreui/react`
- **Mantener el estilo del código**: Seguir automáticamente las reglas de ESLint y Prettier
- **Respetar la arquitectura**: Trabajar dentro de los patrones establecidos de rutas, gestión del estado y estilos

Simplemente abre el proyecto en tu IDE habilitado para IA y el asistente tendrá automáticamente contexto sobre la arquitectura de React, el uso de componentes CoreUI React, los flujos de trabajo de desarrollo y los estándares de código.
